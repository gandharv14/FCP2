# Fresh normalization with no mechanically eligible cells

A fresh `harbor_normalization_producer.prepare` may correctly return
`no_maskable_candidates`, with a null request and no model Call. The owning
consumer previously required a review unconditionally. A fabricated review or
an empty overall PASS would not establish the missing condition.

`harbor_zero_candidate_normalization.validate_no_candidates` is the narrow
read-only alternative. It accepts only the current fresh producer protocol and
root-selected canonical workbook/run. It independently revalidates the complete
audit, current generation pair, original budget and preparation code bindings;
reimports the complete audit; reruns the current normalizer; and requires a
nonempty complete analysis in which every cell is mechanically unclean. Any
surviving maskable cell requires the ordinary independent semantic review.

The exact prepared analysis, draft, evidence and manifest must match that fresh
reconstruction. Source/baseline/curation/audit selections remain unchanged. The
manifest must explicitly contain zero candidate count, empty references and a
null request. Missing evidence is rejected, never repaired during validation.
The original first-normalization snapshot must record integer zero. Full plain
eligibility remains mandatory, including the audit-row floor, exclusion reasons,
no extraction defects, no sentinel and no post-hoc oracle exclusions. A task
which originally had research inputs cannot be downgraded through this path.

The completed-lane and final readiness consumers skip only the absent
normalization Call after this proof succeeds. They still perform their current
exact generated emission, primitive equality, profile, maskability and later
quality checks. Naturalization and other required model Calls remain mandatory.
The completion evidence includes the preparation, complete analysis, original
budget snapshots, original first snapshot and current no-candidate validator.
No request binding or semantic review is fabricated, and no attempt is spent or
reset. Existing reviewed and historical-applicability paths remain unchanged.

This branch supports a genuinely fresh no-candidate preparation. It is not a
migration of an old unbound empty spec, a semantic-review failure, or a missing
model response into a successful plain task.
